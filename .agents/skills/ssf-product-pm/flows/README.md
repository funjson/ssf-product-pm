# flows 目录说明

`flows/` 存放阶段和小阶段的执行规则。

每个 flow 文件回答：

- 什么时候执行。
- 依赖哪些上游输入。
- 读取哪些文档。
- 输出哪些文档。
- 使用哪个模板。
- 触发哪个 Review Gate。
- 如何更新状态资产。
- 常见失败如何 repair。

模板不承担这些规则；模板只定义输出结构。

当前 flow 分层：

- `analysis/`：分析阶段。
- `design/`：设计阶段。
- `change/`：基于 baseline 的局部变更。
- `prototype/`：基于产品规格派生原型输入包。
- `repair/`：结构、状态、证据和追踪修复。
