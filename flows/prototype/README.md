# prototype flows

本目录定义 `prototype-run` 原型输入包生成规则。

prototype-run 目标：

- 从已完成或可用的 `product-spec/04-10` 派生原型工具输入。
- 生成面向 Figma Make / Motiff / Uizard / Figma MCP 的 `prototype-input/`。
- 保留 `SCR / CMP / FEAT / BR / AC` 追踪关系。
- 不改变产品事实源，不新增规格外页面、功能、按钮或业务流程。

prototype-run 是 Design 之后的可选派生运行，不属于 Analysis / Design 主流程。
